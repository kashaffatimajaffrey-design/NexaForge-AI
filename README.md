# NexaForge AI Career Ecosystem

NexaForge is a complete AI-powered career ecosystem designed to help candidates, recruiters, and educational institutions optimize their career and hiring workflows. It brings together personalized CV building, AI-driven mock interviews, video-based assessment, and analytics—all in a seamless, interactive web application.

## Key Features

### 1. Personalized CV Builder
- Build professional CVs with AI suggestions for content optimization.
- Upload your resume or paste text for automated parsing and formatting.
- Multi-language support for global career opportunities.

### 2. AI Mock Interviews
- Simulate real-world interviews based on your CV and target job description.
- Personalized question generation tailored to your role and experience.
- AI evaluation with scores, feedback, and confidence indicators for every answer.
- Track your progress with session analytics.

### 3. Video Vault
- Upload and manage interview or presentation videos.
- Receive AI-driven suggestions and insights to improve delivery, tone, and confidence.

### 4. Recruiter & University Portal
- Recruiter portal to access candidate pipelines, manage hiring nodes, and track performance.
- University admin dashboard for analytics on student placement, skill gaps, and industry readiness.

### 5. Real-time Analytics
- Track your performance, interview readiness, and CV optimization.
- Dashboard visualization with easy-to-understand metrics for both candidates and institutions.

### 6. Multi-Language Support
- Switch between English, French, Urdu, Arabic, and Spanish for a personalized interface experience.

## Technology Stack
- **Frontend:** React, TypeScript, TailwindCSS, Recharts
- **Routing & State:** React Router, React Hooks
- **Icons:** Lucide React
- **AI Integration:** Gemini API (for evaluation and question generation)
- **Build Tool:** Vite
